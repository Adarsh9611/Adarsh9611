## 🚀 Featured Projects

### 🛠️ Maintenance Mapping

A QR-based maintenance mapping system that allows users to scan a QR code associated with a specific equipment or location. After scanning, users can view the mapped asset and submit a complaint describing the issue they are facing, making maintenance reporting easier and more organized.

**Tech Stack:** React • Spring Boot • MySQL • REST APIs • QR Code

---

### 🔢 Digit Recognizer

A machine learning-based digit recognition application that recognizes handwritten digits from user input or uploaded images. The system processes the input image using a trained deep learning model and predicts the corresponding digit.

**Tech Stack:** Python • TensorFlow • Machine Learning • Deep Learning • Computer Vision

---

### 🤖 AI Chatbot – RAG

A Retrieval-Augmented Generation (RAG) based chatbot that allows users to ask questions and receive context-aware responses from a custom knowledge base.

The backend processes the user's query, generates embeddings, performs vector-based retrieval using the knowledge base, and sends the relevant context to the language model to generate the final response.

**Tech Stack:** React • FastAPI • Python • RAG • ChromaDB • Hugging Face Embeddings • LLM
